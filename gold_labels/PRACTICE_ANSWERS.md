# Practice answers

Check your practice sheet against these **after** you have filled it in. Every answer says which words in the report it comes from.

## P1 — TCGA-CM-6170 — a structured US report ('synoptic': Label: value)

| Field | Answer | Why |
|---|---|---|
| Histologic type | adenocarcinoma NOS | 'Tumor Type: Adenocarcinoma'. |
| Mucinous % (if stated) | (blank) | No percentage given - leave blank. |
| Grade | G2 | 'Histologic Grade: Moderately differentiated'. |
| pT | pT2 | 'Tumor Staging ... : pT2'. |
| pN | pN0 | 'Lymph Node Stage ... : NO' - OCR has turned the zero into the letter O. |
| Nodes positive (n) | 0 | 'Number with metastasis: 0'. |
| Nodes examined (n) | 12 | 'Total number examined: 12'. |
| Node status | negative | Nodes were examined and none had cancer. |
| Lymphovascular invasion | absent | 'Lymphovascular Invasion: Not identified'. The perineural line is ignored. |
| Margins | clear | 'Surgical Margins: Free of tumor'. |
| Tumour site | descending | 'Tumor Location: Descending colon'. |
| Post-treatment (ypTNM) | no | Nothing about treatment before surgery. |
| Confidence | sure |  |

## P3 — TCGA-D5-6924 — a Polish / Latin report

| Field | Answer | Why |
|---|---|---|
| Histologic type | adenocarcinoma NOS | 'Adenocarcinoma tubulopapillare' is a growth pattern of ordinary adenocarcinoma. |
| Mucinous % (if stated) | (blank) |  |
| Grade | G1 | '(GI)' - the letter I is the Roman numeral 1. |
| pT | pT3 | 'pT3' in the final line. |
| pN | pN0 | 'pNO' - letter O for zero. |
| Nodes positive (n) | 0 | 'Lymphonodulitis reactiva' = reactive (inflamed) nodes, no cancer. |
| Nodes examined (n) | 8 | '(NO VIII)' = number VIII = 8 nodes. |
| Node status | negative | pN0, reactive nodes only. |
| Lymphovascular invasion | not stated | No L, V or vessel invasion mentioned. |
| Margins | clear | 'Incision lines free of neoplastic lesions'. |
| Tumour site | sigmoid | 'sigmoid colon'. |
| Post-treatment (ypTNM) | no |  |
| Confidence | sure | 'Dukes B, Astler-Coller B2' are other staging systems - ignore them. |
